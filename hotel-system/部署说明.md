# 酒店管理系统 · 部署说明（源码版）

技术栈：Spring Boot 3.2.5（Java 17）+ MySQL 8 + Vue 3 / Vite 5。前端构建产物已预置在
`backend/src/main/resources/static`，因此不装 Node 也能直接打出可运行的 jar。

## 一、环境要求

- JDK 17 及以上（`java -version` 自检）
- Maven 3.8+（或使用 IDE 内置 Maven）
- MySQL 8（本机或远程均可）
- Node 18+（仅在你需要改前端源码时使用）

## 二、配置说明

后端配置：`backend/src/main/resources/application.yml`，全部支持用环境变量覆盖。

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `HOTEL_DB_HOST` | `127.0.0.1` | MySQL 地址 |
| `HOTEL_DB_PORT` | `3306` | MySQL 端口 |
| `HOTEL_DB_NAME` | `hotel_db` | 库名（`createDatabaseIfNotExist=true`，首次自动建库） |
| `HOTEL_DB_USER` | `root` | 数据库账号 |
| `HOTEL_DB_PASS` | 空 | 数据库密码 |
| `HOTEL_JWT_SECRET` | 内置演示串 | 登录令牌密钥，上线必须改成随机长串 |
| `HOTEL_CACHE_TYPE` | `simple` | 缓存类型：`simple` 本地 / `redis` |
| `HOTEL_REDIS_HOST` / `PORT` | `127.0.0.1:6379` | 仅用 redis 时生效 |

服务端口：`server.port` 默认 **8080**。

首次启动会自动建库建表（JPA `ddl-auto=update`）并写入演示数据：4 种房型、15 个房间、
6 位客人、2 个账号。

## 三、部署流程

本工作区已提供免安装运行环境（JRE 17 + MySQL 8），推荐在根目录用 `start-all.ps1` 一键启动。

1. （可跳过）手动建库：`CREATE DATABASE hotel_db DEFAULT CHARSET utf8mb4;`
2. 直接使用已构建好的可执行包：`hotel-system/hotel-system-1.0.0.jar`
   （构建产物 `backend/target/` 已清理；如需重新构建：`cd backend` → `mvn clean package -DskipTests`）
3. 启动：
   `java -jar hotel-system-1.0.0.jar`
   或使用便携 JRE：
   `"C:\Users\Lewisyin\AppData\Local\ai-workspace-runtime\jdk-17.0.20.1+1-jre\bin\java.exe" -jar hotel-system-1.0.0.jar`
4. 访问 `http://localhost:8080`，用下方默认账号登录。

前端源码有改动时：
`cd frontend` → `npm install` → `npm run build` → 把 `frontend/dist/*` 覆盖到
`backend/src/main/resources/static/` → 再重新 `mvn package`。

开发联调：后端 8080 运行，前端 `npm run dev`（5173，`/api` 已代理到 8080）。

## 五、可选：启用 Redis

安装并启动 Redis 后，启动参数加 `--spring.profiles.active=redis`，并按需设置
`HOTEL_REDIS_HOST` / `HOTEL_REDIS_PORT`。不装 Redis 用默认本地缓存即可。

## 六、常见问题

- **连不上 MySQL**：核对地址、端口、账号密码；MySQL 8 需允许公钥检索（配置已含 `allowPublicKeyRetrieval=true`）。
- **8080 被占用**：`java -jar hotel-system-1.0.0.jar --server.port=9000`。
- **页面 404 / 空白**：确认 `src/main/resources/static` 下有 `index.html` 与 `assets/`，然后重新打包。
- **时间/时区不对**：连接串已指定 `Asia/Shanghai`。
