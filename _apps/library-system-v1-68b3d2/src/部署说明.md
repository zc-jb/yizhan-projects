# 图书管理系统（Spring Boot + Vue3 + MySQL）

> 本部署说明由「技术驿站 · 作品上线」自动补齐（2026/11/8 22:31:30）。

## 环境要求
- JDK 17+（Spring Boot 3 需要 17 及以上）
- MySQL 8（Redis 可选）

## 直接启动
```
java -jar *.jar
```
默认 8080 端口；数据库地址可用环境变量 `HOTEL_DB_HOST` 等覆盖，见 `application.yml`。
首次启动会自动建表并写入演示数据。

## 一键容器运行
```
docker compose up -d
```
访问 <http://localhost:8090>。
