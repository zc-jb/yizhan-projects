# 图书管理系统 · 部署说明

Spring Boot 3.2 + Vue 3 + MySQL 8 的图书馆管理后台。功能包含图书 / 分类 / 读者 / 借阅管理与逾期统计，首次启动会自动生成随机的图书、读者与借阅演示数据。

## 一、环境要求

| 组件 | 版本 |
| --- | --- |
| JDK | 17 及以上（运行用 JRE 17 即可） |
| MySQL | 8.0 及以上 |
| Node.js | 18 及以上（仅前端二次开发需要） |
| Maven | 3.8 及以上（仅后端二次构建需要） |

## 二、最快启动（jar 包）

1. 启动 MySQL，并确保可以用账号连接；数据库不需要手动创建，程序会自动建库 `library_db`。
2. 在解压目录执行：

```bash
java -jar library-system-1.0.0.jar --server.port=8090
```

3. 打开 http://127.0.0.1:8090 ，使用演示账号登录：

| 账号 | 密码 |
| --- | --- |
| admin | 123456 |
| librarian | 123456 |

### 数据库连接配置

默认连接 `127.0.0.1:3306 / root / 空密码`。可通过环境变量或启动参数覆盖：

```bash
set LIB_DB_HOST=127.0.0.1
set LIB_DB_PORT=3306
set LIB_DB_USER=root
set LIB_DB_PASS=你的密码
set LIB_DB_NAME=library_db
set LIB_PORT=8090
java -jar library-system-1.0.0.jar
```

也可以直接修改解压目录下的 `application.yml`（同目录文件优先级高于 jar 内置配置）。

## 三、演示数据

首次启动且库为空时，`DataSeeder` 会写入：

- 8 个图书分类
- 60 种图书（随机书名、作者、ISBN、出版社、年份、馆藏数量）
- 28 位读者（随机姓名、性别、手机号、借书证号）
- 60 余条借阅记录（含借阅中、已逾期、已归还三种状态）

数据由固定随机种子生成，重复删除数据库后重建可复现。清空演示数据只需执行：

```sql
DROP DATABASE library_db;
```

## 四、从源码构建

```bash
# 1. 构建前端
cd frontend
npm install
npm run build          # 产物在 frontend/dist

# 2. 把前端产物放进后端静态资源
#    将 dist 内所有文件复制到 backend/src/main/resources/static/

# 3. 构建后端
cd ../backend
mvn -DskipTests package
# 产物：target/library-system-1.0.0.jar
```

前端已预构建并打进 jar，直接运行 jar 即可，不要求安装 Node。

## 五、Docker 部署

```bash
docker compose up -d --build
```

默认映射 `8090:8090`，MySQL 数据保存在 `mysql-data` 卷中。首次启动等待约 30 秒（建表 + 生成演示数据）。

## 六、接口速览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/auth/login | 登录，返回 12 小时有效的 token |
| GET | /api/health | 健康检查 |
| GET | /api/stats | 概览统计 |
| GET/POST/PUT/DELETE | /api/books | 图书管理 |
| GET/POST/PUT/DELETE | /api/categories | 分类管理 |
| GET/POST/PUT/DELETE | /api/readers | 读者管理 |
| GET | /api/borrows?status= | 借阅列表（active / overdue / returned / all） |
| POST | /api/borrows | 借阅登记（借期 30 天） |
| POST | /api/borrows/{id}/return | 归还 |

除登录与健康检查外，其余接口需在请求头携带 `X-Token`。

## 七、常见问题

- **启动报 `Communications link failure`**：MySQL 未启动或端口/账号配置错误。
- **页面空白**：确认访问的是 `http://127.0.0.1:8090/`，不要用 `file://` 直接打开 html。
- **8080 被占用**：改用 `--server.port=8091` 等其他端口。
- **中文乱码**：数据库需使用 `utf8mb4`，程序会自动创建。
