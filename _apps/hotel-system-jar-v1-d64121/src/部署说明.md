# 酒店管理系统 · 部署说明（运行版）

自包含 jar：前端已打包进 `static`，本机只需 Java 17+ 与 MySQL 8。

## 一、配置说明（二选一）

方式 A · 环境变量（推荐）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `HOTEL_DB_HOST` | `127.0.0.1` | MySQL 地址 |
| `HOTEL_DB_PORT` | `3306` | MySQL 端口 |
| `HOTEL_DB_NAME` | `hotel_db` | 库名，首次启动自动创建 |
| `HOTEL_DB_USER` | `root` | 数据库账号 |
| `HOTEL_DB_PASS` | 空 | 数据库密码 |
| `HOTEL_JWT_SECRET` | 内置演示串 | 登录密钥，上线务必换成随机长串 |

Windows PowerShell：

```powershell
$env:HOTEL_DB_PASS="你的数据库密码"
java -jar hotel-system-1.0.0.jar
```

Linux / macOS：

```bash
export HOTEL_DB_PASS="你的数据库密码"
java -jar hotel-system-1.0.0.jar
```

方式 B · 改配置文件

与 jar 同目录的 `application.yml` 会被自动读取，直接编辑
`server.port`、`spring.datasource`、`app.jwt.secret` 后启动即可。

## 二、部署流程

1. 安装 JDK 17+（`java -version` 确认）与 MySQL 8 并启动；
2. 按上面的方式配置数据库（不改配置则连接本机 `root` 空密码）；
3. 启动：`java -jar hotel-system-1.0.0.jar`，换端口加 `--server.port=9000`；
4. 浏览器访问 `http://localhost:8080`；
5. 首次启动自动建库建表并写入演示数据（房型、房间、客人、账号）。

## 三、默认账号

| 账号 | 密码 | 角色 |
|---|---|---|
| `admin` | `123456` | 管理员 |
| `reception` | `123456` | 前台 |

上线前请修改密码与 `HOTEL_JWT_SECRET`。

## 四、可选：Redis

默认本地缓存即可运行；装了 Redis 可加参数 `--spring.profiles.active=redis`，
并用 `HOTEL_REDIS_HOST` / `HOTEL_REDIS_PORT` 指定地址。

## 五、常见问题

- **启动报数据库连接失败**：检查 MySQL 是否启动、账号密码是否正确。
- **端口被占用**：`--server.port=9000` 换端口。
- **页面空白**：确认访问的是 jar 启动后的 `http://localhost:8080`，不要直接双击 html。
