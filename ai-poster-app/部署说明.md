# AI 海报工坊 · 部署说明

纯前端静态站点：解压后是 `index.html` + `css/` + `js/`，无需后端、无需数据库。

## 一、可选的配置项（都在浏览器里填）

| 配置 | 位置 | 作用 | 是否必填 |
|---|---|---|---|
| Pexels Key | 右上 ⚙️ 设置 | 搜高清正版图（pexels.com/api 免费申请） | 否 |
| AI 接口地址 / Key / 模型 | 左侧「✨AI」面板 | AI 生图、AI 文案，兼容 OpenAI 格式，如 `https://api.xx.com/v1/chat/completions`、`gpt-4o-mini` | 否 |
| 水印文字 / 默认加水印 | 右上 ⚙️ 设置 | 导出图片时叠加水印 | 否 |

配置和作品都存在本机浏览器（localStorage），换浏览器/清缓存会丢失。
对外正式使用时，建议把 AI Key 改由后端代理转发，避免 Key 暴露在前端。

## 二、部署流程

方式 A · 静态托管（推荐）
1. 把解压后的全部文件上传到站点根目录（Nginx / Apache / IIS / OSS / CDN / Netlify 均可）；
2. 访问 `http(s)://你的域名/` 即可使用。

方式 B · 本地预览
- 在本工作区根目录执行 `powershell -ExecutionPolicy Bypass -File .\start-all.ps1`（推荐，地址 http://127.0.0.1:5173）；
- 或单独启动静态服务：
  `node "C:\Users\Lewisyin\AppData\Local\ai-workspace-runtime\static-server.mjs" "e:\AI海报制作\ai-poster-app" 5173`；
- 也可直接双击 `index.html`（部分浏览器对 `file://` 有限制）。

完整环境与端口说明见根目录 `本地运行说明.md`。

Nginx 参考：

```nginx
server {
  listen 80;
  server_name poster.example.com;
  root /var/www/ai-poster-app;
  index index.html;
}
```

## 三、使用流程

1. 打开页面 → 左侧「模板」挑一个版式；
2. 依次添加文字 / 图片 / 背景 / 贴纸，右侧面板调字号、颜色、位置；
3. 需要 AI 素材时，在「✨AI」面板提交描述生成图片或文案；
4. 右上「💾 保存」存到本地作品库，「⬇ 导出」可选 PNG / JPG / PDF、清晰度与水印；
5. 重要作品用「导出 .json 工程」备份，换设备时「导入 .json 工程」还原。

## 四、注意事项

- 模板插画、二维码为本地离线生成，断网也能用；只有 Pexels 搜图与 AI 需要联网。
- 作品数据保存在当前浏览器，清理浏览器数据会丢失，请及时导出工程文件备份。
